## Overview

If Then Dungeon is a concept on the workshop bench. The idea is a dungeon adventure that helps younger players explore programming ideas through play.

There is no playable demo. The features and experience described here are planned design, not an account of an existing game.

## Why We Made This

We are interested in games that make thinking part of the fun. This concept asks what a dungeon adventure might look like if programming ideas were part of the adventure itself.

## What Makes It Different

The intended audience is roughly ages 10–15. That is an informal design target, not a formal age rating or a claim of classroom testing.

The workshop is the right place for this idea while the design takes shape. If it becomes playable, this same project record can move to the games collection without losing its identity.

The illustration on this page is an original concept placeholder—not a screenshot or final game logo.
